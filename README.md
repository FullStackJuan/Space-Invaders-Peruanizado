# Space-Invaders-Peruanizado
Proyecto de fin de curso para Programación orientada a Objetos en la Universidad Tecnológica del Perú basado en el clásico juego de las árcades para ordenadores actuales tanto en windows como en Linux
Sin fines de lucro, se busca rehacer el juego desde un punto de vista distinto con assets de uso libre
----------------------------------------
IMPORTANTE
Para correr el juego entraras a tu editor de codigo de confianza (VS code, Intellij, etc) y correras dentro de lwjgl3 y buscaras el ejecutable "lanzador.java"
